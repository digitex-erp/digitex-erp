# Bell24H - Emergency Services Directory

A responsive web application providing quick access to emergency service numbers with a modern, user-friendly interface.

## Features

- 📱 One-click emergency calling
- 🎨 Modern, responsive design
- 💬 Interactive help assistant
- 🚨 Clear emergency guidelines
- 📞 Support for multiple emergency services

## Emergency Numbers Included

- Police: 100
- Fire Department: 101
- Medical Emergency: 108
- Women Helpline: 1091
- Child Helpline: 1098
- Disaster Management: 1070

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Deployment

This project is optimized for Vercel deployment.
